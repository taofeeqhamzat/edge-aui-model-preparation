# Task 40.5 — ONNX Export, Bundle v2 and Framework Handoff

## Description

Export the semantic target head and integrate it with the browser runtime through a versioned
manifest, without overwriting the previous intervention-head artifact.

## Acceptance criteria

- [ ] ONNX graph inputs are `sequence_input (batch, T, 18)` and `context_input (batch, 6)`; output
      is semantic outcome logits `(batch, vocabulary_size)`.
- [ ] INT8 quantization is applied; PyTorch/ONNX parity is verified within tolerance.
- [ ] Model size and browser inference latency are measured; report actual values, not targets.
- [ ] `bundle.json` v2 records vocabulary/version, dataset version/hash, code commit, seed,
      environment, metrics, input/output contract and artifact hashes.
- [ ] Framework can load the new artifact through configuration/manifest; vocabulary/order is read
      from the manifest, not hardcoded.
- [ ] Previous `intervention_head*.onnx` and `bundle/v1.0.0` remain untouched and reproducible.
- [ ] Framework model-version/provider reporting reflects the new artifact.
- [ ] Tests cover graph contract, parity, quantization load, bundle schema/hashes and framework
      load.
- [ ] `python3 -m pytest tests/test_intervention_head_export.py tests/test_reproducibility_bundle.py -q`
      passes.
