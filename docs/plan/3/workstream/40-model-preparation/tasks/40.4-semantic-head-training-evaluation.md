# Task 40.4 — Semantic Target-Head Training and Evaluation

## Description

Train a new target head on the semantic outcome vocabulary using participant traces, preserving
the foundation GRU and the previous five-class intervention head as reproducible artifacts.

**This task is blocked until usable participant traces exist.** Scripted traces may smoke-test the
code path but cannot satisfy the evaluation acceptance criteria.

## Acceptance criteria

- [ ] Semantic head output dimension equals the approved vocabulary size (14 proposed) and accepts
      `(sequence, context)`.
- [ ] Foundation GRU checkpoint is preserved; freeze/partial/full ablation is reproducible.
- [ ] Training config records semantic taxonomy, dataset version, seed, history/horizon, class
      weights and head class count.
- [ ] Evaluation reports per-class P/R/F1, support, macro-F1, weighted-F1, confusion matrix,
      majority baseline, class distribution and participant-held-out/task-level results.
- [ ] Prediction lead time and calibration/reliability are reported where support permits.
- [ ] No future data, post-intervention evidence or task-lifecycle label leaks into inputs/targets.
- [ ] Previous five-class head/bundle remains unchanged and reproducible.
- [ ] Results distinguish scripted pipeline evidence from participant-derived evaluation.
- [ ] Tests cover output dimension, input contract, no-leakage assertions and metric availability.
