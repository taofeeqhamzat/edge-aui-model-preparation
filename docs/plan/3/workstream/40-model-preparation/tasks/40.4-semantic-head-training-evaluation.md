# Task 40.4 — Semantic Target-Head Training and Evaluation

## Description

Train a new target head on the semantic outcome vocabulary using participant traces, preserving
the foundation GRU and the previous five-class intervention head as reproducible artifacts.

**Status: executed 2026-11-20** on 77 verified participant sessions. Scripted traces may
smoke-test the code path but cannot satisfy the evaluation acceptance criteria.

## Acceptance criteria

- [x] Semantic head output dimension equals the approved vocabulary size (14) and accepts
      `(sequence, context)`.
- [x] Foundation GRU checkpoint is preserved; freeze/partial/full ablation is reproducible.
- [x] Training config records semantic taxonomy, dataset version, seed, history/horizon, class
      weights and head class count.
- [x] Evaluation reports per-class P/R/F1, support, macro-F1, weighted-F1, confusion matrix,
      majority baseline, class distribution and held-out/task-level results at the declared
      split unit (session-bounded).
- [x] Prediction lead time and calibration/reliability are reported where support permits.
- [x] No future data, post-intervention evidence or task-lifecycle label leaks into inputs/targets.
- [x] Previous five-class head/bundle remains unchanged and reproducible.
- [x] Results distinguish scripted pipeline evidence from participant-derived evaluation.
- [x] Tests cover output dimension, input contract, no-leakage assertions and metric availability.

## Result (2026-11-20)

- Dataset `v2.2.0-participant`: 9,686 examples from 77 verified sessions, session-bounded splits.
- Ablation test macro-F1: E1 0.1105, **E2 0.1297 (selected on validation)**, E3 0.0767;
  majority baseline 0.0841.
- E2 test: accuracy 0.1271, macro-F1 0.1297, weighted-F1 0.1102, top-3 0.7590, MRR 0.4724,
  ECE 0.2913.
