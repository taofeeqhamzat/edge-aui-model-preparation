# Task 40.2 — Semantic Target Generation and Dataset v2

## Description

Add semantic target generation and a versioned semantic dataset that mirrors the framework's
semantic rules while retaining the generic labels/columns for legacy and ablation.

## Acceptance criteria

- [ ] A semantic target module derives the approved 14 outcomes from events after the anchor
      window within the configured horizon.
- [ ] Rules mirror the TypeScript layer on shared fixtures: committed change, form submit, report
      selection, reset, navigation/backtrack; ignore hover/substring/system actions.
- [ ] `TARGET_DATASET_SCHEMA` v2 adds `target_task_outcome`, `target_task_outcome_id`,
      `task_outcome_vocabulary_version`, `task_definition_version` and label provenance; existing
      generic columns remain.
- [ ] Dataset version is explicit (for example `v2.0.0-semantic`); v1.0.0 is not overwritten.
- [ ] Every example retains required provenance fields and source event IDs.
- [ ] Tests cover label correctness, boundary conditions, missing semantic outcome, provenance and
      schema.
- [ ] Dataset can be built from scripted captures; this is a pipeline result, not participant
      evidence.
- [ ] `python3 -m pytest tests -q` passes.
